## Run on Mac
    cd ~/Downloads/"event management project"
    python3 -m venv .venv && source .venv/bin/activate
    pip install -r requirements.txt
    flask --app run run --debug
Then open http://127.0.0.1:5000

## Get latest code later
    cd ~/Downloads/"event management project"
    git pull
